# 🎧 Harmony Player v6

A multi-source music UI using:
- Spotify embeds
- Audius API
- Node.js backend
- Clean glass UI

## Features
- Search music
- Spotify embedded playback
- Audius streaming API
- Unified interface
- No backend music scraping

## Deploy (Render)
1. Push to GitHub
2. Connect repo to Render
3. Use render.yaml
4. Deploy

## Run locally
npm install  
npm start
